Preguntas frecuentes

¿Qué es el valor de referencia?

Es el valor de mercado de esa versión y año modelo para un carro en buen estado y con el kilometraje esperado para su edad. Sobre ese valor aplicamos el ajuste por kilometraje.

¿Por qué el kilometraje cambia el valor?

Un carro que ha recorrido más de lo normal para su edad tiene más desgaste. Comparamos tu kilometraje con el esperado{% if km_per_year_label %} ({{ km_per_year_label }} km por año){% endif %}: cerca de lo esperado no cambia nada; si tiene más, el valor baja poco a poco{% if penalty_cap_label %}, hasta un {{ penalty_cap_label }} %{% endif %}; si tiene menos, sube{% if bonus_cap_label %} hasta un {{ bonus_cap_label }} %{% endif %}.

¿Por qué en los clasificados piden más por un carro como el mío?

Los anuncios muestran lo que pide el vendedor, no el precio final de la venta, que suele cerrarse más abajo después de negociar. Además, cada anuncio depende del estado, los accesorios y la urgencia de quien vende.

¿Qué no tiene en cuenta la valoración?

El estado mecánico y de la carrocería, los accidentes, el color, los accesorios, la documentación y la ciudad de venta. Para una cifra definitiva hace falta un peritaje.

¿Por qué algunas versiones dicen «sin valoración disponible»?

Porque no tenemos un valor de referencia para esa versión y año. En ese caso preferimos no mostrar una cifra antes que inventarla. Prueba con un año o una versión cercana.

¿Guardan mis datos?

No pedimos placa, matrícula ni datos personales, y no guardamos tus consultas. Tu navegador solo recuerda si prefieres el modo claro u oscuro.

Qué tener en cuenta

Cómo influye el kilometraje

Comparamos el kilometraje con el esperado para la edad del carro{% if km_per_year_label %} ({{ km_per_year_label }} km por año){% endif %}. Cerca de lo esperado, el valor no cambia. Si tiene más, baja de forma gradual{% if penalty_cap_label %} hasta un máximo de {{ penalty_cap_label }} %{% endif %}; si tiene menos, sube{% if bonus_cap_label %} hasta un {{ bonus_cap_label }} %{% endif %}.

Qué no se evalúa

El estado mecánico, los accidentes, la documentación ni la ciudad de venta. Los valores de referencia corresponden al mercado de Bogotá, con vehículos en buen estado.

Qué significa la cifra

Es una valoración orientativa de AutoValor, no un avalúo ni una tasación oficial. El ajuste por kilometraje usa parámetros iniciales que aún no están calibrados con ventas reales.
